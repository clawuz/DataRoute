# Melody Bank Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grammar-made melody phrases baked into a JSON bank, a deterministic selector behind `phraseMotifs`, an A/B flag `?melody=bank|walk`, and an evaluation report.

**Architecture:** Python generator + exporter (`scripts/music/melody/`), `globe/src/personal/melody-bank.json` (generated, committed), `melody-bank.ts` selector, `idiom.ts` delegation, `compose.ts` option and rest support. Spec: `docs/superpowers/specs/2026-10-27-melody-bank-design.md` (all forms, the bank format, the selector rules). Approved plan: `/Users/okilavuz/.claude/plans/refactored-tumbling-rose.md`.

**Tech Stack:** Python 3 stdlib (`unittest`, numpy optional) in `scripts/music/melody/`; TypeScript, vitest (`cd globe && npx vitest run`, `npx tsc --noEmit`).

## Global Constraints

- Deterministic everywhere (seeds from hashes; no wall-clock, no `Math.random`, Python `random.Random(seed)` only).
- Default melody stays `walk`: goldens and shared links do not change in this plan.
- The bank file is generated by `scripts/music/melody/export_bank.py` and committed; size < 1 MB minified (version 2 compact format).
- Licensing: this step uses no external corpus (grammars written from the card idioms and `docs/music-instrument-idioms.md`); say so in the report.
- Docs: `docs/music-data-mapping.md` (a "Melody bank" section with a Where cell), `docs/music-melody-model-report.md` (generated), a short README `scripts/music/melody/README.md` (how to regenerate).
- No push, no deploy.
